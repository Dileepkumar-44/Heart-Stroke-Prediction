# ❤️ Heart Stroke Risk Prediction Using Machine Learning

# 📌 Project Overview

The Heart Stroke Risk Prediction project is a Machine Learning-based application designed to analyze patient health data and predict the likelihood of a stroke. It uses various health and demographic attributes to identify potential stroke risk factors and support early risk assessment.

The project applies data preprocessing, exploratory data analysis, feature selection, and machine learning algorithms to build a predictive model.

# 🎯 Objectives

Predict the likelihood of stroke based on patient health information.
Analyze important health and lifestyle factors associated with stroke risk.
Apply machine learning algorithms for classification.
Evaluate model performance using appropriate evaluation metrics.
Demonstrate how data science can support early health risk assessment.
